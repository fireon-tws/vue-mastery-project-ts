# Agent Instructions for vue-mastery-project-ts

Welcome! If you are an AI assistant or agent working on this project, please read this document carefully to understand the context, rules, and structure of this repository.

## 📁 Repository Structure & Context

This is a Vue 3 project using TypeScript and the Composition API.

*   **`docs/`**: This folder contains important project documentation, such as `project-plan.md` and `vue-mastery-checklist.md`. Always review these files to understand the current goals, requirements, and checklists before making structural changes.
*   **`.agent/skills/`**: This folder contains specialized instructions, tools, and workflows for you. If a task seems complex or requires a specific process, check if a relevant skill exists here first.
*   **`src/`**: The main application source code.

## ✅ Do's

*   **Do** write Vue 3 code using the `<script setup>` syntax and Composition API.
*   **Do** use TypeScript for all components and logic. Ensure strict type safety.
*   **Do** consult the `docs/` folder to align your work with the overarching project plan and checklists.
*   **Do** refer to `.agent/skills/` when performing specific or repeatable tasks within this repository.
*   **Do** write concise, modular, and maintainable components.

## ❌ Don'ts

*   **Don't** use Vue 2 Options API (`data()`, `methods: {}`, etc.). Stick exclusively to Vue 3 Composition API.
*   **Don't** bypass TypeScript checks or use `any` unless absolutely necessary and verbally justified.
*   **Don't** deviate from the established project plan in `docs/project-plan.md` without explicit user permission.
*   **Don't** create new workflows or configuration files outside of the designated `.agent/` directory unless requested.
